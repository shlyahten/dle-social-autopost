# Настройка публикации ВКонтакте (VK API)

Плагин публикует записи на стену сообщества ВКонтакте через официальный API ВКонтакте версии 5.131+.

В качестве метода авторизации используется **Ключ доступа сообщества (Community Access Token)**. Данный ключ бессрочный, не зависит от личной страницы администратора и не сгорает при смене паролей.

---

## Шаг 1: Получение токена сообщества

1. Откройте ваше сообщество (группу или публичную страницу) ВКонтакте под учетной записью с правами **«Владелец»** или **«Администратор»**.
2. В правом меню перейдите в раздел **«Управление»**.
3. В меню настроек выберите **«Работа с API»**.
4. Откройте вкладку **«Ключи доступа»** и нажмите кнопку **«Создать ключ»**.
5. В открывшемся окне обязательно отметьте галочками права:
   - [x] **Разрешить приложению доступ к стене** (`wall`);
   - [x] **Разрешить приложению доступ к фотографиям** (`photos`) — необходимо для прикрепления картинок к записям;
   - [x] **Разрешить доступ к документам** (опционально).
6. Подтвердите создание ключа (через SMS или подтверждение в мобильном приложении VK).
7. Скопируйте полученную строку ключа (начинается с `vk1.a...`).

---

## Шаг 2: Определение ID сообщества

1. В разделе **«Управление»** сообщества обратите внимание на адресную строку браузера:
   `https://vk.com/club123456789` или `https://vk.com/public123456789`.
2. Число после `club`, `public` или `event` и есть ID группы (например, `123456789`).
3. Если у сообщества настроен короткий буквенный адрес (например `vk.com/my_cool_portal`):
   - Откройте любой пост на стене сообщества. В URL будет: `vk.com/wall-123456789_100`. Число между минусом и подчеркиванием — это и есть ID группы.
   - Либо откройте любую фотографию в альбоме сообщества: в URL будет `photo-123456789_...`.

---

## Шаг 3: Настройка плагина в DLE

1. Перейдите в админпанель DLE: `Сторонние модули` -> `Автопостинг VK & Telegram` -> вкладка `Настройки`.
2. Поставьте галочку **«Включить отправку в VK»**.
3. Вставьте полученный **Токен сообщества VK**.
4. В поле **ID группы ВКонтакте** укажите только цифры (без знака минус, например: `123456789`).
5. Настройте параметры публикации:
   - **Публиковать от имени группы** (рекомендуется включить);
   - **Добавлять подпись автора** (опционально).
6. Нажмите кнопку **«Сохранить настройки»**.
7. Перейдите на вкладку **«Диагностика и тест»** и нажмите **«Проверить подключение к VK»**.
   - Должно появиться уведомление об успешном подключении с названием вашей группы.

## Шаблон записи ВКонтакте

ВКонтакте не поддерживает HTML-теги в тексте записи на стене, поэтому используйте стандартный текст и теги подстановки:
- `{title}` — заголовок новости;
- `{short-story}` — краткий текст публикации;
- `{full-story}` — полный текст публикации;
- `{link}` — ссылка на новость на сайте;
- `{tags}` — хэштеги публикации;
- `{category}` — категория новости;
- `{date}` — дата публикации.

### Пример шаблона:
```text
{title}

{short-story}

Читать полностью: {link}

{tags}
```

При наличии главного изображения в новости оно будет автоматически загружено в специальный альбом стены сообщества и прикреплено к записи.
