# Настройка планировщика задач (CRON)

Плагин **DLE Social AutoPost** оснащен интеллектуальной очередью задач и гибридным механизмом отправки:
1. При добавлении/редактировании новости плагин производит **мгновенную попытку отправки** в соцсети.
2. Если в этот момент связь с API Telegram или VK дала сбой (таймаут, сетевой лаг, ошибка лимитов), задача автоматически помещается в очередь `dle_autopost_queue`.
3. Если новость добавлена с **отложенной датой публикации** в будущем (Scheduled News) или находится на модерации (`approve = 0`), она публикуется автоматически через CRON в момент наступления даты.

---

## Вариант 1: Запуск через системный crontab сервера (Рекомендуется)

Запуск через консоль PHP интерпретатора обеспечивает максимальную скорость и не зависит от таймаутов веб-сервера.

1. Подключитесь к серверу по SSH или откройте раздел планировщика Cron в панели управления хостингом (cPanel, ISPmanager, FastPanel, aaPanel).
2. Добавьте задачу с интервалом запуска раз в 1-2 минуты:
   ```bash
   */2 * * * * /usr/bin/php /var/www/html/cron/autopost.php >/dev/null 2>&1
   ```
   *(Замените `/var/www/html/` на реальный абсолютный путь к корню вашего сайта, а `/usr/bin/php` — на путь к вашему бинарнику PHP).*

### Проверка работы в консоли:
Вы можете запустить команду вручную:
```bash
php /var/www/html/cron/autopost.php
```
Вывод покажет статистику выполнения:
```text
DLE AutoPost CRON Worker Completed.
Scheduled queued: 0
Queue processed:  2 (Succeeded: 2, Failed: 0)
Execution time:   0.0412s
```

## Вариант 2: Запуск по HTTP через внешний Web-Cron

Если ваш хостинг не предоставляет доступ к консоли SSH/CLI:

1. В админпанели DLE в разделе **«Автопостинг VK & Telegram»** скопируйте сформированный HTTP URL:
   ```text
   https://вашсайт.ru/cron/autopost.php?key=ВАШ_СЕКРЕТНЫЙ_КЛЮЧ
   ```
2. Настройте запуск через `wget` или `curl` в планировщике хостинга:
   ```bash
   */2 * * * * curl -s "https://вашсайт.ru/cron/autopost.php?key=ВАШ_СЕКРЕТНЫЙ_КЛЮЧ" >/dev/null 2>&1
   ```
   Либо воспользуйтесь бесплатными внешними сервисами web-cron (cron-job.org, easycron.com).

При вызове скрипта через HTTP ответ возвращается в формате JSON:
```json
{
    "status": "ok",
    "scheduled_queued": 0,
    "queue_processed": 1,
    "queue_succeeded": 1,
    "queue_failed": 0,
    "execution_time_s": 0.0823
}
```

## Вариант 3: Интеграция со штатным `cron.php` движка DLE

При установке плагина через XML автоматически внедряется хук в файл `engine/modules/cron.php`.
Если на вашем сайте уже настроен стандартный крон DataLife Engine:
```bash
/usr/bin/php /var/www/html/cron.php
```
очередь автопостинга будет дополнительно обрабатываться при каждом запуске стандартного крона сайта.
