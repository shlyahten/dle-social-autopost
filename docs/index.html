DLE Social AutoPost

Автоматическая кросс-публикация пресс-релизов и новостей в Telegram и ВКонтакте для CMS DataLife Engine 13.0 — 21.0

Скачать ZIP для DLE (v1.1.1) Скачать XML-плагин Репозиторий GitHub

Telegram Bot API

Публикация в каналы с поддержкой HTML-форматирования, инлайн-кнопок, обрезки текста, кастомного Endpoint API и SOCKS5/HTTP прокси.

ВКонтакте API v5.131+

Бессрочный токен сообщества, прямая загрузка картинок из DLE на стену группы и настраиваемые шаблоны постов.

Очередь и CRON

Гибридный режим: моментальная отправка на сайте + автоматическая фоновая очередь для отложенных постов и повторов при сбоях сети.

Установка через панель управления DLE

  1. Скачайте архив dle-social-autopost-v1.1.1.zip.
  2. Откройте панель управления DLE → «Управление плагинами».
  3. Нажмите «Загрузить плагин» и выберите скачанный архив.
  4. Перейдите в появившийся раздел «Автопостинг VK & Telegram» в меню и укажите токены.
