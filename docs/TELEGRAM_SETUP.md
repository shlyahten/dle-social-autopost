# Настройка публикации в Telegram

Для автоматической публикации новостей в Telegram вам понадобятся:
1. **Токен бота (Bot Token)**;
2. **ID или публичный юзернейм канала**;
3. Добавление бота в администраторы канала с правом публикации сообщений.

---

## Шаг 1: Создание бота в Telegram

1. Откройте приложение Telegram и найдите официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду:
   ```text
   /newbot
   ```
3. Задайте понятное имя боту (например, `МойСайт Новости`).
4. Задайте уникальный username бота, оканчивающийся на `bot` (например, `mysite_news_bot`).
5. @BotFather пришлет сообщение с токеном доступа:
   ```text
   Use this token to access the HTTP API:
   1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ123456789
   ```
6. Скопируйте этот токен.

---

## Шаг 2: Создание канала и добавление бота

1. Создайте канал в Telegram (публичный или приватный).
2. Перейдите в **Управление каналом** -> **Администраторы** -> **Добавить администратора**.
3. Найдите созданного бота по его username (например, `@mysite_news_bot`) и добавьте его.
4. Предоставьте боту право **«Публикация сообщений»** (Post Messages).

---

## Шаг 3: Определение Chat ID канала

### Для публичного канала:
Если у вашего канала есть публичная ссылка вида `t.me/my_site_news`, то в поле **ID или Username канала** в настройках плагина укажите:
```text
@my_site_news
```

### Для приватного канала:
У приватных каналов числовой ID имеет формат `-100xxxxxxxxxx`.
Чтобы узнать ID приватного канала:
1. Перешлите любое сообщение из вашего канала боту **[@userinfobot](https://t.me/userinfobot)** или **[@getidsbot](https://t.me/getidsbot)**.
2. Бот покажет поле `Forwarded from channel: ID: -1001234567890`.
3. Скопируйте число со знаком минус и префиксом `-100`.

---

## Шаг 4: Настройка в панели DLE

1. Откройте админпанель DLE: `Сторонние модули` -> `Автопостинг VK & Telegram` -> вкладка `Настройки`.
2. Поставьте галочку **«Включить отправку в Telegram»**.
3. Вставьте **Токен Telegram бота**.
4. Вставьте **ID или Username канала** (`@channel` или `-100...`).
5. Нажмите кнопку **«Сохранить настройки»**.
6. Перейдите на вкладку **«Диагностика и тест»** и нажмите **«Проверить подключение к Telegram»**.
   - Должно появиться сообщение об успешном подключении с указанием имени бота и заголовка канала.

## Шаблоны и теги оформления

В поле «Шаблон сообщения Telegram» можно использовать HTML-разметку и теги:
- `{title}` — заголовок новости;
- `{short-story}` — краткое содержание новости (очищенное от HTML и BB-кодов);
- `{full-story}` — полное содержание новости;
- `{link}` — ссылка на публикацию на сайте (с UTM-метками, если включены);
- `{tags}` — теги публикации в виде `#хэштегов`;
- `{category}` — название категорий;
- `{date}` — дата публикации.

### Пример шаблона:
```html
<b>{title}</b>

{short-story}

{tags}
```
*Примечание: Если включена опция «Кнопка-ссылка (Inline Button)», ссылка на сайт будет прикреплена в виде стильной кнопки под сообщением.*

## Обход блокировок ТСПУ / РКН

### Как проверить, заблокирован ли Telegram (нужен ли прокси)?

В панели управления плагином перейдите на вкладку **«Диагностика и тест»** и нажмите кнопку **«Запустить проверку доступности»**:
- Плагин выполнит замер DNS, TCP и TLS рукопожатия напрямую к `api.telegram.org` и выдаст наглядный вердикт:
  - 🟢 **Прокси не требуется**: сервер имеет прямой беспрепятственный доступ к Telegram;
  - 🔴 **Требуется прокси или зеркало**: запросы к Telegram блокируются ТСПУ/РКН на сервере (зависают по таймауту или сбрасываются). В этом случае настройте один из способов ниже:

### Способ А: Кастомный URL API (Зеркало / Reverse Proxy) — Самый надежный

В поле **«Кастомный URL API Telegram»** вместо `https://api.telegram.org` укажите адрес вашего реверс-прокси.

Пример простого конфига Nginx на любом зарубежном VPS:
```nginx
server {
    server_name tg-proxy.yourdomain.com;
    listen 443 ssl http2;

    location / {
        proxy_pass https://api.telegram.org;
        proxy_ssl_server_name on;
        proxy_set_header Host api.telegram.org;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_connect_timeout 15s;
        proxy_read_timeout 30s;
    }
}
```
После этого в настройках плагина укажите: `https://tg-proxy.yourdomain.com`.

Также поддерживаются:
- **Cloudflare Workers** (бесплатный обратный прокси в 5 строк JavaScript кода);
- Официальный локальный бинарник `telegram-bot-api` (например: `http://127.0.0.1:8081`).

### Способ Б: Встроенный SOCKS5 / HTTP Прокси

В блоке «Прокси для Telegram» включите опцию и укажите:
- Тип: `SOCKS5` или `HTTP`
- Адрес: `ip:порт` (например: `127.0.0.1:9050` или `192.168.1.100:1080`)
- Логин:пароль (если прокси требует авторизации).
