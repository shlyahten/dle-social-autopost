# DLE Social AutoPost (VK & Telegram)

[![DataLife Engine](https://img.shields.io/badge/DLE-13.0%20--%2021.0-blue.svg)](https://dle-news.ru)
[![PHP Version](https://img.shields.io/badge/PHP-7.4%20|%208.0%20|%208.1%20|%208.2%20|%208.3%20|%208.4-8892BF.svg)](https://php.net)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Профессиональный плагин для CMS **DataLife Engine (DLE)**, предназначенный для автоматической кросс-публикации пресс-релизов, новостей и статей в **Telegram-канал** и сообщество **ВКонтакте**.

Плагин построен с максимальным использованием возможностей движка DLE: штатной виртуальной файловой системы плагинов, встроенного API, механизма категорий, доп. полей (xfields) и системы планировщика задач (CRON).

---

## 🚀 Ключевые возможности

- ⚡ **Гибридный механизм отправки**: мгновенная публикация при сохранении новости + отказоустойчивая очередь в MySQL при сетевых сбоях и таймаутах API.
- ⏰ **Поддержка отложенных публикаций DLE**: новости с датой публикации в будущем (`approve = 1`, `date > NOW()`) или находящиеся на модерации автоматически отправляются в соцсети в момент их наступления через CRON.
- 🎯 **Управление публикацией**:
  - Фильтрация по категориям сайта (например, только для категорий «Пресс-релизы» или «Новости компаний»).
  - Ручные чекбоксы-переключатели в форме добавления и редактирования новостей в админпанели (`Отправить в Telegram`, `Отправить в ВКонтакте`) со статусом «уже отправлено».
- 🖼️ **Умный поиск и прикрепление изображений**:
  1. Приоритетное получение постера из указанного дополнительного поля (xfield);
  2. Если поле пустое — автоматический парсинг первого изображения из текста новости (поддержка `<img>`, тегов DLE `[img]`, `[thumb]` и комментариев кэша изображений);
  3. Прямая загрузка локальных файлов без лишних HTTP-запросов и поддержка удаленных изображений.
- ✈️ **Интеграция с Telegram**:
  - Публикация в публичные и приватные каналы через Telegram Bot API;
  - Форматирование текста (HTML: жирный шрифт, курсив, ссылки);
  - Стильная инлайн-кнопка (URL Button) с настраиваемым текстом (например, «Читать на сайте»);
  - Интеллектуальная обрезка текста с сохранением слов (до 1024 символов для подписи к фото и до 4000 для текста);
  - **Кастомный Endpoint API**: возможность указать свой URL API Telegram (собственный reverse-proxy на Nginx, локальный telegram-bot-api сервер или Cloudflare Worker), а также встроенная поддержка SOCKS5 и HTTP прокси;
  - **Сетевая диагностика**: встроенный тест замера DNS, TCP и TLS пинга для проверки стабильности подключения к эндпоинтам.
- 🌐 **Интеграция с ВКонтакте**:
  - Публикация на стену группы/паблика через VK API v5.131+;
  - Авторизация через бессрочный **Токен сообщества** (Community Access Token);
  - Загрузка картинок на сервер VK с прикреплением к записи стены;
  - Опции публикации от имени сообщества и подписи автора.
- 📊 **Сквозная аналитика (UTM-метки)**:
  - Автоматическое добавление настраиваемых параметров `utm_source`, `utm_medium`, `utm_campaign` к ссылкам для Telegram и VK.
- 🛠️ **Полнофункциональный модуль админпанели**:
  - **Настройки**: удобное управление всеми параметрами модуля;
  - **Очередь задач**: мониторинг статусов (`pending`, `processing`, `failed`, `done`), повторный запуск и удаление;
  - **Журнал публикаций**: история отправки, ID постов в соцсетях, подробные тексты ошибок API при сбоях;
  - **Диагностика и тест**: проверка подключения к Telegram-боту и VK API в 1 клик, а также тестовая ручная отправка любой существующей новости по ее ID.
- 📦 **Установка в 1 клик и чистое удаление**: готовый дистрибутив в формате штатного менеджера плагинов DLE (XML/ZIP). При удалении плагина из панели DLE автоматически вычищаются все файлы, таблицы БД и настройки.

## ⚡ Быстрый старт

### 1. Установка в DLE

1. Скачайте архив `dist/dle-social-autopost-v1.1.0.zip` или XML-файл `dist/dle-social-autopost.xml`.
2. В панели управления DLE откройте **«Управление плагинами»** и нажмите **«Загрузить плагин»**.
3. Выберите скачанный файл.
4. Модуль готов к работе! В списке модулей админпанели появится раздел **«Автопостинг VK & Telegram»**.
